# Read the FMEA in your browser

Open **[the FMEA viewer](fmea_view/index.html)**. It works locally without an
internet connection. For a local web address, run:

```bash
source myenv/bin/activate
python -m src.reliable.cli serve
```

Then visit **http://127.0.0.1:8765**.

## What you can do

- Search for a failure, component, symptom or action.
- Filter by source document and review status.
- Click a failure to read every FMEA field, qualifiers, conditions and evidence.
- Open the original PDF at the cited physical page.
- Download a readable CSV or JSON containing the structured fields and sources.
- Use **Statements & review** for claims that have not entered FMEA.
- Use **Source documents** to see exactly which pages were processed.

“Assistant source check” means the extraction was compared with its source; it
does not mean technical approval. The viewer cannot approve records. Missing
fields remain **Not stated**: no accepted information fills that field; the PDF may
still contain information that was missed or awaits review.

A small explicit list in `src/reliable/fmea.py` groups equivalent failure names
such as **failed bearing → bearing failure**. Causes and symptoms combine only
within the same source section and with identical recorded operating conditions.
Bearing wear and bearing damage remain separate. Each cause keeps its own row.
Original wording is retained in quotes and the JSON's `original_value`; the alias
list and builder version are saved with each new FMEA export. No reviews change.

## Additional PDFs

The original Fluke pilot is retained. A first set of **three technical selections
from each of five additional PDFs** has also been processed:

| Document | Selected physical page | Focus |
|---|---:|---|
| ABB motor manual | 25 | Starting, stalling, power failure |
| AC troubleshooting guide | 3 | Bearings, winding, unbalanced load |
| Timken bearing manual | 12 | Repair, damage, installation |
| EPRI motor maintenance guide | 54 | Moisture, corrosion, lubrication |
| Lincoln polyphase guide | 6 | Starting problems and matched causes/remedies |

These are selected passages, **not complete-document coverage**. Each PDF has its
own run, citations and review history. Groq's EPRI interruption was resumed; all
15 selected passages completed. Some quotations or roles remain invalid or
unreviewed and are excluded from FMEA.

Selections are defined in [config/document_profiles.json](config/document_profiles.json).
Each selector must match exactly one original text block; changed or ambiguous
layouts stop for inspection. All blocks from selected pages remain preserved.
Explicit selection order keeps table context and column continuations together.
The AC guide's missing first-column text is flagged rather than invented.

```bash
# Parse the configured selections without API calls.
python -m src.reliable.cli library

# Extract/resume those selections, with up to 3 new calls per document.
python -m src.reliable.cli library --extract

# Refresh the browser view after extraction or review; no API calls.
python -m src.reliable.cli view
```

The output folder is `fmea_view/`. It contains the HTML viewer, CSV/JSON exports
and copies of the cited PDFs, so the folder can be opened offline. Regenerating it
refreshes this display; previous raw runs and reviewed exports remain preserved.

## Structure for later work

FMEA JSON keeps component, function, failure, cause, effect, symptom, diagnosis,
maintenance action, evidence and review provenance. Each cause stays a separate
scenario. A cause-specific remedy is attached only to that cause's row. Qualifiers
and conditions remain in both the detailed view and export.

This is a readable organization of the extracted knowledge. No ontology, fault-tree
gates, probabilities or risk ratings are generated by the viewer.
